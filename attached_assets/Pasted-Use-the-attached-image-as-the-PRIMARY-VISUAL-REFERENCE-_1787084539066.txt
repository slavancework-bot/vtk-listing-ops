6. CRITICAL INCLUDED-ANSWER VALIDATION FIX
==================================================

The current EmployeeScreen implementation contains logic equivalent to:

isIncludedComplete = totalQuestions === 0 || true

That makes Included verification effectively always complete.

Fix this.

The employee must make an explicit Included decision when Included questions exist.

However, checking zero boxes is a legitimate answer because NONE may be included.

Therefore do NOT use:
“at least one checkbox selected”
as the completion rule.

Instead introduce an explicit decision state.

Recommended behavior:

When Included questions exist, show a control such as:

[ CONFIRM INCLUDED SELECTION ]

or

[ NONE OF THESE ARE INCLUDED ]

A better UX may be:

- Employee checks applicable components.
- If one or more are selected, Included verification becomes complete after interaction/confirmation.
- If none are included, employee explicitly selects:
  NONE OF THESE

The application must distinguish:

UNANSWERED

from

ANSWERED — NONE INCLUDED

This distinction is critical.

Do not silently treat an untouched checklist as NONE.
